# MKT Colorado town page layout

Use [Allenspark](../allenspark.html) as the master layout for every town and destination guide. [Arapahoe Basin](../arapahoe-basin.html) shows how to adapt it for a ski destination.

1. Use the shared site header and Explore Colorado banner.
2. Open the guide with the region and county, destination name as the H1, and a one-sentence introduction.
3. Add the cream Colorado A–Z story panel with a local description and four quick facts.
4. Put the guide navigation immediately below the story panel and above the artwork and mug. Use All, Attractions, Parks & Recreation, Dining, Shopping, Events, and History & Culture. Give each link a relevant section or destination. Use the site’s events page when the guide has no local event section.
5. Directly below the navigation, place the artwork on the left and the artwork story and souvenir mug on the right when those assets are ready. Use the mug preview, current price, and direct product link for published mugs. Use the same responsive stacking as Allenspark.
6. Follow with the destination introduction, history and “What It Is Known For” feature, local character, independent businesses, visitor information, map, and shared footer with sponsors.
